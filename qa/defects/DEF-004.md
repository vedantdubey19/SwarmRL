# DEF-004: server/ directory lacks committed package.json

- **Defect ID**: DEF-004
- **Title**: server/ directory lacks a committed package.json file
- **Severity**: S3 (Minor)
- **Priority**: P3 (Medium)
- **Component**: Relay / Server Deployment
- **Commit Hash Tested**: `1bb20365573883f0d41a0e4f310d737a95a015b0`
- **Environment**: macOS 27.2 (arm64), Node.js v26.12.1

## Steps to Reproduce
1. Inspect the `server/` directory:
   `ls -la server/`
2. Check for `package.json`.

## Expected Result
A standard `package.json` declaring dependencies (`ws`) should exist in `server/` so that `npm install --prefix server` works deterministically.

## Actual Result
`server/` contains only `schema.json` and `server.js`. Running `npm install --prefix server ws` forces npm to auto-generate a package.json or fail if offline.

## Frequency
Always.

## Workaround
Use root `node_modules` where `ws` is installed, or run `npm init -y` inside `server/`.
