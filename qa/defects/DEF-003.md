# DEF-003: Two high-severity dependency vulnerabilities detected in frontend

- **Defect ID**: DEF-003
- **Title**: npm audit reports 2 high-severity vulnerabilities in frontend devDependencies (`vite`, `source-map-js`)
- **Severity**: S3 (Minor)
- **Priority**: P3 (Medium)
- **Component**: Frontend / Security
- **Commit Hash Tested**: `1bb20365573883f0d41a0e4f310d737a95a015b0`
- **Environment**: macOS 27.2 (arm64), Node.js v26.12.1

## Steps to Reproduce
1. In `frontend/` directory, run:
   `npm audit`

## Expected Result
Zero vulnerabilities reported in production and development dependency tree.

## Actual Result
Two high-severity security advisories reported:
1. `source-map-js` (1.0.0 - 1.2.1): Event-loop denial of service via indexed source-map section offsets (GHSA-68fv-2mgg-jv7q).
2. `vite` (8.3.0 - 8.3.2): Arbitrary command execution on Windows and cross-origin script execution vulnerabilities (GHSA-698v-4r3x-3vcv, GHSA-9jrq-w75r-8gcw).

## Frequency
Always.

## Workaround
Run `npm audit fix` in `frontend/` to upgrade `vite` and `source-map-js` to patched versions.
